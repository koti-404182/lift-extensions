# Lift extensions

Browser extensions that get data out of web pages. Everything runs in your browser.

- **SheetLift**: tables to Excel, CSV, Sheets, Markdown, JSON. [Privacy policy](sheetlift/privacy.html)
- **LinkLift**: every link on a page to CSV, Excel, Markdown, JSON. [Privacy policy](linklift/privacy.html)
